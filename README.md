# Eclipse Starter for Jakarta EE
This is a sample application generated by the Eclipse Foundation starter for Jakarta EE.

You can run the application by executing the following command from the directory where this file resides. Please ensure you have installed a [Java SE 8+ implementation](https://adoptium.net/?variant=openjdk8) appropriate for your Jakarta EE version and runtime choice (we have tested with Java SE 8, Java SE 11 and Java SE 17). Note, the [Maven Wrapper](https://maven.apache.org/wrapper/) is already included in the project, so a Maven install is not actually needed. You may first need to execute `chmod +x mvnw`.

Ignore clean if don't need to build again.

```
set -a
source .env
set +a
./mvn clean spring-boot:run
```

a. Has HttpServlet.
b. Has auth support. - run target/bin/add-user.sh to add app user to user to group.
c. Has persistence with REST.

### Curl cmds

```
// for auth
curl --user raga:Passw0rd -v http://localhost:8080/jakartaee-hello-world/rest/hello

// for pers
curl -X POST \
 http://localhost:8080/jakartaee-hello-world/rest/coffees \
 -H 'Content-Type: application/json' \
 -d '{
 "id": 1,
 "name": "Coffee-A",
 "price": "2.75"
}'

PORT=8080
HOST=http://localhost
REGION="austin"
curl -X GET $HOST:$PORT/fetchstatics?truncate=true\&region=$REGION
curl -X GET $HOST:$PORT/stops/loadAll?truncate=true\&region=$REGION
curl -X GET $HOST:$PORT/stops
curl -X POST $HOST:$PORT/stops/coord  -d '{ "latitude": 30.253, "longitude": -97.703 }' -H 'Content-Type: application/json'
curl -X GET $HOST:$PORT/trips/loadAll?truncate=true\&region=$REGION
curl -X GET $HOST:$PORT/trips

REGION="vancouver"
curl -X GET $HOST:$PORT/stops/loadAll?truncate=true\&region=$REGION

// all stops with limit set to 3 now
curl -X GET $HOST:$PORT/stops

// stops near me
curl -X POST $HOST:$PORT/stops -d '{ "latitude": 49.202, "longitude": -122.9164 }' -H 'Content-Type: application/json'

curl -X GET $HOST:$PORT/trips/byTripId?tripid=1
curl -X GET $HOST:$PORT/trips/byRouteId?routeid=1

curl -X GET $HOST:$PORT/routes/loadAll?truncate=true\&region=$REGION
curl -X GET $HOST:$PORT/routes

```

More info [here](https://jakarta.ee/learn/starter-guides/how-to-store-and-retrieve-data-using-jakarta-persistence/)

Once the runtime starts, you can access the project at http://localhost:8080/jakartaee-hello-world.

### Logging
Using mvn, these switches help.

```
    -e for error
    -X for debug
    -q for only error
```
